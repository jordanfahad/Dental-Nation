# DN-001 — GMB reviews sync: reconcile removals

Mode: repo
Branch: codex/DN-001

Goal: the reviews sync currently APPENDS from the source sheet and never
removes rows for reviews Google has deleted, so the synced table overcounts
(79 rows vs 60 publicly visible on 14 Sep 2026 — 19 were removed in a Google
spam sweep). Make the sync reconcile: any review present in `gmb_reviews`
but absent from a non-empty sync payload gets soft-deleted (a `removed_at`
timestamptz, set once, cleared if the review reappears). Live readers then
count only rows where `removed_at IS NULL`.

- Landmine (PROJECT-THREAD): an EMPTY sync payload must never mark anything
  removed — reconcile only when the payload is non-empty and parsed cleanly.
- Landmine: do not change the /impact hero tile — it stays a hardcoded dated
  fact until this reconciliation has run in prod and been verified against
