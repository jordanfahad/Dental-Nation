## Proof contract and enforcement

The enforceable rule is **same metric ID, definition version, period, scope and source revision means the same raw result and formatted figure**. Matching dates alone cannot guarantee equality after a source correction. A patient trace count also need not equal an appointment count; the proof must identify its row unit.

## One computation contract

Create `lib/metrics/{context,registry,read,format,proof}.ts` as a proposed boundary. Readers accept one immutable context: `from`, `to`, `timezone`, `dateBasis`, `clinic`, `channel`, `campaign`, `programme`, `comparisonFrom`, `comparisonTo`, `comparisonMode`, `definitionVersion`, `snapshotId`. Clinic values are `all|al-wasl|dr-tosun|al-maher`. Each registry entry declares supported dimensions. A clinic on shared enquiries is rejected/explained, not applied as an empty zero; unsupported Al Maher patient results return unavailable.

Return `MetricResult { id, definitionVersion, value, unit, numerator, denominator, status, scope, coverage, sourceRevision, observedAt, refreshedAt, proofUrl }`. Status distinguishes complete, partial, stale, unavailable, outside-scope and measured zero. For group results list participating and missing clinics. Never convert a failure into a mock or zero in a production leadership figure. Amounts use integer minor units or exact decimal accumulation, no rounding per channel; percentages carry their raw numerator and denominator. Common display: counts integer, AED headlines grouped whole currency with exact cents in proof/export, cost ratios 2 decimals, ratings 2 decimals, rates one decimal. Email and page use the same display formatter at the same precision.

M01 must initially preserve the post-DN-029 hybrid identity rule. M02 is a separate proposed known-person union. Read lineage must reuse `selectWebsiteEnquiries` and tagged-phone precedence, not fork that logic. Bookings/attendance are appointment-day events, not booking-created cohorts. Billing is bill-date net, with signed adjustments and explicit cancellation policy. Provider charge lines, Finance and cash are different bases. GBP/advertising/GSC source daily aggregates retain the provider day/timezone label; an aggregated daily value cannot be re-bucketed to Dubai from missing timestamps. All supplied timestamp events are bucketed in Asia/Dubai.

The current two rounding points in Growth, duplicated brand regex, positive-Map-view completeness proxy and mutable review/member state must not survive inside the new authoritative contract. Introduce availability metadata without assuming `social_insights.value` accepts null: it is NOT NULL per the project thread. Do not infer a reported zero from omitted Google values. A correctly named sampled brand share is acceptable without a new API integration.

## Make proof reproducible

Before a new email is built, read one consistent source manifest and materialise immutable aggregate metric results, definition text/version and any aggregate decomposition needed for proof. Give that snapshot an opaque authenticated ID. Read the page and email from that same snapshot, including comparisons. A source watermark alone is insufficient for tables that overwrite reviews, replies, removals or membership counts; retain the aggregate evidence or source-version history. Snapshot IDs are locators, not access grants. Sensitive row detail remains behind existing permissions and retention rules.

The proof drawer shows definition, unit, source, exact dates, supported clinic/channel scope, source refresh, saved time, coverage and authorised detail link. Default is the original emailed result. An explicit latest view can show revised figures and the revision reason. Old emails lack snapshot identifiers and sometimes even date parameters. Their exact historic number cannot be reconstructed reliably from the URL alone. Preserve the original route and legacy definition, show that the saved result is unavailable, and offer a clearly labelled current same-scope result. Never falsely claim historical parity or silently replace the value. A migration cannot manufacture old evidence.
